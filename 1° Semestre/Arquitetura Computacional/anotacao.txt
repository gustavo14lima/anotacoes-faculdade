    O cérebro humano é similar a um supercomputador, por ser capaz de realizar multplas tarefas ao mesmo tempo, realizar calculos, processamento, controlar diferentes partes do
    corpo e por ter um centro de trafico aereo; Neuronios seriam como processadores, captando, processando e enviando informações; Sinapses são as conexões entre os processadores
    responsavel pela transmissão de informação de um neuronio para outro; O lobulo frontal é como se fosse o modulo central, responsavel pela tomada de decisão, realização de calculos
    complexos e resolução de problemas. Computadores são maquinas que ajudam a resolver problemas seguindo um conjunto de passos (especificando o que o computador deve fazer); Os
    computadores deve fazer as seguintes operações básicas: entrada, processamento, saida e (as vezes) armazenamento de dados. O sistema computacional é o conjunto de componentes 
    integrados para funcionar como se fosse apenas um, com o objetivo principal manipular dados, para ter uma informação util; por ter uma grande diversidade de tamanho, componentes
    e desempenho, é necessário categoriar os tipos de computador. Ambito geral: computadores de escolas/escritorios que tem como objetivo realizar grande varaiedade de tarefas.
    Ambito especifico: computadores para realizar tarefas muito especficias e reduzidas. Computadores Cientificos: computadores para realizar calculos e pesquisas cientificas.
    Computadores comercial: equipamentos de escritorios, realização rapida e seguras de tarefas. O hardware (toda a parte física do sistema computacional) é o conjuto de 
    perifericos de um sistema computacional, sendo externos (perifericos de entrada e saida) e internos (componentes necessários para o funcionamento correto de um computador).
    Software é uma sequencias de intruções lógicas que alimenta o processamento, em outras palavras, são toda a parte programavel de um sistema (SO, Linguagem Programação e etc.).
    Firmware: Software realizado por uma Linguagem de Programação de baixo nivel que é responsavel pelo gerenciamento do sistema de hardware, como por exemplo, a BIOS. O sistema 
    operacional é um conjunto de software que interpreta códigos e gera uma interface entre o usuário e o PC; ele assume o controle o PC só se ele estiver armazenado em disco (para 
    que a BIOS o localize); O sistema operacional também é responsavel pelo gerenciamento e controle de softwares que o usuário executa.

    Ao longo do tempo o ser humano sentiu a necessidade de criar novos sistemas númericos (conjunto de regras e simbolos para representar números, definindo como os números são organizados
    e escritos, possibilitando a contagem e calculo. Todo sistema númerico tem uma base), sendo alguns deles: decimal (base 10),binario (base 2), octal (base 8), hexadecimal (base 16).
    Com exceção da decimal, os demais são utilizados nas areas de circuitos digitais, automação e ambientes computacionais. Sistema Decimal (base 10), vai de 0 até 9, em cada posição do 
    algoritmo muda seu valor (5 no inicio, 5 no meio [50] e etc.); Sistema bionario (base 2) representa dois algoritmos 0 e 1, usa exponeciação na base dois; Sistema octal (base 8), ele 
    representa três bits do sistema binario (ou seja, para representar o 3 seria 011), indo de 0 à 7; Por fim, o hexadecimal (base 16) representa quatro bits do sistema binario
    (ou seja, para representa o 11 seria 1011), ele vai de 0 à F (sendo A o 10 e F o 15). Lembre-se, o caminho da luz é o binario, ou seja, caso eu quero ir de octal para decimal, eu baso pelo
    binario antes (octal -> binario -> decimal ), isso serve para qualquer transformação.

    A CPU (unidade central de processamento) é como se fosse um cérebro humano, pois é ele que interpreta intruções e coordena a execução de tarefa. Para fazer parte do sistema, a CPU 
    precisa estar conectada na placa mãe a partir do soquete, que pode-se assimilar a tomada e a CPU o conector (cabo do carregador). Essa conexão com a placa mãe garante a comunicação 
    do processador com a placa mãe, possibilitando que todo sistema trabalhe de forma integrada. O Clock Interno é a frequencia com que o processador executa seus ciclos de operações, medido
    em Hz (Hertz). Podemos representar ele como um coração, a cada batida é uma instrução processada por segundo, quanto mais rapido o coração, mais instruções processadas por segundo (e ele tambémm
    mantem o computador vivo). Cada ciclo é como se fosse uma oportunidade de realizar uma tarefa/ação, em outras palavras, determina quantas operações podem ser realizadas por segundo. 
    O overclock aumenta a velocidade do clock, mas cuidado, aumentar a frequência também exige maior consumo de energia e gera mais calor, que além disso, preojudica a vida util do processador
    e tem mais chances de perdas. A ULA (unidade lógica e aritmetica) é a parte do processador responsavel por realizar operações matematicas e logicas. Ela quem faz as operações matematicas 
    (as 4 principais), com as informações recebidas pelo processador. Todos os programas de um computador, parcialmente depende da ULA. O nucleo de um processador, é um componente fisico, que realiza 
    a tarefas simultaneas a partir da quantidade de nucles, ou seja, caso eu tenho dois nucleos, eu posso realizar duas tarefas simultaneamente sem preojudição ou perca de desempenho. Agora, o Threading 
    é um nucleo lógico, sendo assim, um componente lógico, ele é como se fosse uma extensão/subdivisão do nucleo, geralmente, o Threading é duas vezes maior que o nucleo.

    Bit é a menor unidade que um computador pode armazenar ou pocessar, sendo um valor binário (representa apenas 0 ou 1). Um byte é o conjunto de 8 bits, todo o sistema
    operacional é orientado a bytes, ele é a unidade padrão para codificar e processar informações dentro de um SO. O computador trabalha com um conjunto de bytes, um sistema computacional/operacional não consegue trabalhar com 1 bit, ele precisa de pelo menos 1 byte para fazer um processamento. O conjunto de 8 bits sempre vai representar algum 
    caracter no sistema operacional, por exemplo, o 01100001 pode representar o 0. Em um representação de byte, o bit com mais importância (o primeira da esquerda para a 
    direita) representa o bit signal, no qual, ele é responsavel por representar ao computador se o número é positivo ou negativo, se o bit signal for 0, o número é positivo, se 
    o bit signal for 1, o número é negativo. Para transformar um número de positivo para negativo, utilizamos o complemento de dois:
        1° passo: inverter a polaridade do byte (o que é 0 vira 1 e o que é 1 vira 0)
        2° passo: adicionar 1 no bit com menos importância (o primeiro da direita para esquerda)
    Para inverter um número de negativo para positivo, apenas realize o mesmo processo. Quando um byte tem o seu byte signal representando algum valor (por exemplo o número 252 
    que tem 8 bits de comprimento), deve-se adicionar um byte com todos os seus bits representando 0 (Ex: 11111100 -> 00000000 11111100). No inicio da computação, cada 
    fabricante de computador tinha uma sequencia de 8 bits para representar um caracter, só que isso gera consequencias horriveis, o fabricante B não consegue ler o arquivo 
    feito pelo fabricante A. Com isso surgiu a tabela ASCII 128, um código padrão americano com o papel de padronizar os caracteres com seus respectivos bytes.O bit signal é 
    sempre representado por 0, para diferenciar números negativos de positivos, assim, com 7 bits para trabalho. Como é representado em 7 bits possibilita representar 128 caracteres no total. Atualmente, os códigos de 0 à 31 são códigos de controle, de 32 à 128, são códigos de impressão. Como a tabela ASCII 128 era um padrão americana, letras 
    acentuadas e outro simbolos não foram definidos, com isso surgiu uma extensão da ASCII 128, utilizando o 8 bits para representar alguns elementos faltantes, assim criando a 
    ASCII 256 (como está utilizando mais um bit, a quantidade de caracteres dobra). Essa expansão permitiu a inclusão de caracteres específicos de idiomas. Entretando, essa 
    extensão foi um grande avanço, mas com um problema, cada regial tem seus simbolos e acentos. O Unicode seria a solução para esse problema, sendo a solução definitiva para o 
    problema de representação de caracteres. O Unicode utiliza um número maior de bits para representar caracteres, mas em contrapartida, ele representa todos os simbolos 
    existente, desde caracteres padrões, simbolos de outras linguas, emojis e simbolos de gráficos e matematicos.
