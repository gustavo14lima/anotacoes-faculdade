# 18. Desvio Padrão

# 18.1 Desvio Padrão

Como visto anteriormente, o desvio padrão serve para analisar a variança que um determinado conjunto de dados tem em relação a média, ou seja, mostra o grau de dispersão dos dados em torno da média. Por exemplo, se o desvio padrão das notas de uma turma resultou em 2, significa que cada temos dois pontos de diferença no desvio padrão e em cada nota de aluno, ou seja, a próxima nota com mais quantidade seria 8 e 4, depois 10 e 2.

Entender como o desvio padrão funciona é crucial para entender a distribuição dos dados e também, pode ser utilizado para tomada de decisão. 

Temos diferentes níveis de resultado de desvio padrão, sendo eles:
- **Desvio Padrão Nulo**: quando o desvio padrão é nulo, isso mostra que todos as variáveis possuem seu valor igual a média, desta forma, não existe uma variação dos dados.
- **Desvio Padrão Baixo**: quando o desvio padrão está baixo, significa que os valores das variáveis estão próximos a media, o que resulta que os dados são relativamente homogêneos (ou seja, são quase iguais, possuem uma certa semelhança)
- **Desvio Padrão Alto**: quando o desvio padrão está alto, significa que os valores das variáveis estão mais afastados e dispersos da média, o que resulta em uma maior heterogeneidade nos dados (ou seja, dados mais diferentes).

Vale ressaltar que a utilização do desvio padrão está presente em diversos setores, como em finanças, análise de dados, controle de qualidade e entre outros.

## 18.2 Regra Empírica (68-95-99,7)

A Regra Empírica (68-95-99,7), diz que, em uma distribuição de dados aproximadamente normal, estabelece que:
- Cerca de 68% dos dados estão dentro de um desvio padrão da média (ou seja, o desvio padrão nulo).
- Aproximadamente 95% dos dados estão dentro de dois desvios padrão da média (alto e baixo).   
- Quase todos os dados (99,7%) estão dentro de três desvios padrão da média.

## 18.3 Desvio Padrão Populacional e Desvio Padrão Amostral

O desvio padrão populacional é utilizado quando você tem dados de todos os elementos que compõem o grupo de interesse, ou seja, quando eu tenho todos os valores das variáveis de um certo grupo. Por exemplo, quando eu tenho todas as notas dos alunos de uma turma. Ele é mais usando quando é possível  coletar dados de 100% do grupo.

Agora, o desvio padrão amostral é utilizado quando você tem dados de apenas uma amostra (um subconjunto representativo) tirada da população, ou seja, ao invés de coletar todos os dados de um determinado grupo, eu apenas pego uma certa porcentagem dos dados. Essa maneira de coletar dados de toda a população costuma ser impossível ou custoso demais, por isso que sempre tiramos uma certa amostra encima do total. Por exemplo, ao invés de eu coletar todas as opiniões de sorvete de cada individuo de são paulo, eu apenas pego uma cidade ou bairro em específico e monto as minhas análise a partir deste valor.
